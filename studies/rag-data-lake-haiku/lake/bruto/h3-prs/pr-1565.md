# PR #1565: fix(cookie): size cookie chunks by their encoded length

Mesclado em 2026-10-03. Autor: breken-ai.

## Summary

`setChunkedCookie` splits the raw value every `chunkMaxLength` (default 4000) characters. Each chunk is then percent-encoded by `setCookie` (`encodeURIComponent` by default), and that encoding makes it longer: `"`, `{`, `:`, `,` and spaces become 3 bytes, and non-ASCII characters become 6–12 bytes. So the stored chunks can be far larger than the ~4KB the chunking is meant to stay under.

```ts
setChunkedCookie(event, "cart", JSON.stringify(cart)); // 7501 characters
// Set-Cookie: cart=__chunked__2
// Set-Cookie: cart.1=… (9195 bytes)
// Set-Cookie: cart.2=… (7932 bytes)
```

Browsers drop cookies over 4096 bytes, so the chunks never come back. On the next request `getChunkedCookie` sees `__chunked__2` with the chunks missing and returns `undefined`. The data is lost without any error.

A second failure in the same slicing: `value.slice()` cuts at UTF-16 indexes, so a chunk boundary can split a surrogate pair (an emoji, for example). `encodeURIComponent` then throws `URIError: URI malformed`, and the handler fails with a 500.

Session cookies aren't affected: the sealed value is URL-safe ASCII. It hits apps that put JSON or user text into chunked cookies.

## Fix

A new internal helper, `splitCookieValue`, splits the value on code point boundaries, so a surrogate pair is never split. Each chunk is the longest run whose encoded form, using the same `encode` as `setCookie` (`options.encode` or `encodeURIComponent`), fits in `chunkMaxLength`. The helper measures whole candidate chunks (gallop, then bisect), so custom encoders like base64 whose length isn't additive per character are sized correctly too. A code point that can't fit even alone throws before any header is written. For values that don't grow when encoded (such as sealed sessions), the chunks are exactly the same as before, so all existing chunk snapshots are unchanged. The chunk-count cap still applies, and the helper stops as soon as it's exceeded.
