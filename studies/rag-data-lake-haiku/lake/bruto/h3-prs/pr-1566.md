# PR #1566: fix(mime): add .mjs and .cjs to COMMON_MIME_TYPES

Mesclado em 2026-10-02. Autor: okxint.

`.mjs` (ES module) and `.cjs` (CommonJS module) files are absent from `COMMON_MIME_TYPES`. When `serveStatic` serves a `.mjs` file, `getType` returns `undefined` and no `Content-Type` header is set.

Browsers enforce strict MIME checking for `<script type="module">` — a missing content-type causes a network error and the module fails to load entirely.

The fix adds both extensions mapped to `"text/javascript"`, consistent with `.js` and with [RFC 9239](https://www.rfc-editor.org/rfc/rfc9239).
