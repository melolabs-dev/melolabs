# PR #1580: fix(static): match file extensions case-insensitively

Mesclado em 2026-10-17. Autor: harshit-d3v.

`getType` looks the extension up as-is, so `/photos/IMG_0001.JPG` or `/LOGO.PNG` gets no type from `serveStatic`. on node the response then goes out as `text/plain; charset=UTF-8`, on web with no content-type at all. uppercase extensions are pretty common for camera uploads.

lowercased the extension before the lookup. the custom `getType` option still gets the extension as written.

added a test that fails on main for both web and node:

```
AssertionError: expected 'text/plain; charset=UTF-8' to be 'image/jpeg'
```
