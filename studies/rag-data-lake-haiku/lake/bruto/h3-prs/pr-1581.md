# PR #1581: fix(static): serve .wasm as application/wasm

Mesclado em 2026-10-17. Autor: harshit-d3v.

`.wasm` isn't in `COMMON_MIME_TYPES`, so `serveStatic` sends it as `text/plain; charset=UTF-8` on node and with no content-type on web. `WebAssembly.instantiateStreaming()` requires `application/wasm` and rejects the response otherwise.

`instantiateStreaming(await app.request("/module.wasm"))` on node 22:

```
main: TypeError: WebAssembly response has unsupported MIME type 'null'
this: ok
```

added it to the table, with a test that fails on main for web and node.
