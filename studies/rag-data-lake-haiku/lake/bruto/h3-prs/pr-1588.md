# PR #1588: test: accept exact loopback addresses in fingerprint checks

Mesclado em 2026-10-17. Autor: xiehuanyi.

The Node fingerprint test fails on a dual-stack local listener when the peer address is `::ffff:127.0.0.1`. This is a valid loopback address, but the existing expectation accepts only `0.0.0.0` or `::1` (and does not anchor both alternatives).

Accept the exact loopback forms `127.0.0.1` and `::ffff:127.0.0.1` alongside the existing values, with the entire expression anchored. Arbitrary addresses and partial string matches still fail. No runtime behavior changes.
