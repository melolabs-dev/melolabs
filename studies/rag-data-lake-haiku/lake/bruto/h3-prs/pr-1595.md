# PR #1595: fix(response): omit HEAD body for default errors

Mesclado em 2026-10-17. Autor: maxazure.

Resolves #1594.

Without an `onError` hook, a missing HEAD route or a handler throwing `HTTPError` returns a JSON body through the web Response API. Node's HTTP transport strips it, and a no-op `onError` hook already makes the web response body empty.

Let the generated default error response continue through the existing Response normalization path so HEAD bodies are removed consistently. The implementation changes one line; error serialization, status/statusText, error headers, cookies, and public APIs remain unchanged.

The regression matrix covers missing HEAD routes, synchronous/asynchronous HTTPError handlers, GET JSON responses, both hook configurations, preserved error headers, and hook invocation counts. Before the fix, three web HEAD cases fail and the other 17 matrix cases pass. The minimal reproduction is in #1594.
